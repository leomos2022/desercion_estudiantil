# Diagrama de Cierre de Proyecto

**Actividades Imprescindibles y Documentos Clave**

A continuación se presenta un diagrama profesional que ilustra la relación entre las actividades imprescindibles para el cierre de un proyecto y los documentos clave generados en este proceso.

---

**Actividades Imprescindibles:**
- Verificación de Entregables
- Aceptación Formal del Cliente
- Liquidación Financiera
- Lecciones Aprendidas
- Liberación de Recursos
- Archivo de Documentación
- Cierre de Contratos

**Documentos Clave:**
- Acta de Cierre
- Lista de Verificación
- Informe de Lecciones

---

**Relaciones:**
- La Verificación de Entregables, Aceptación Formal del Cliente, Liquidación Financiera, Liberación de Recursos y Cierre de Contratos generan el Acta de Cierre.
- Las Lecciones Aprendidas generan tanto la Lista de Verificación como el Informe de Lecciones.
- El Archivo de Documentación genera la Lista de Verificación.

---

**Resumen Visual:**

| Actividad Imprescindible         | Documento Clave Generado         |
|----------------------------------|----------------------------------|
| Verificación de Entregables      | Acta de Cierre                   |
| Aceptación Formal del Cliente    | Acta de Cierre                   |
| Liquidación Financiera           | Acta de Cierre                   |
| Lecciones Aprendidas             | Lista de Verificación, Informe de Lecciones |
| Liberación de Recursos           | Acta de Cierre                   |
| Archivo de Documentación         | Lista de Verificación            |
| Cierre de Contratos              | Acta de Cierre                   |

---

Este diagrama facilita la comprensión del flujo de actividades y la generación de documentos esenciales para un cierre de proyecto exitoso.
